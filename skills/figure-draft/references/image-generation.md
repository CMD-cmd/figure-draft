# 三种风格与定向迭代

适用于实际位图生图与编辑。调用时读可用 `imagegen` Skill 与当次工具说明。默认使用内置生成能力，不因科研任务自动切换收费 API。

已有 `.af`、SVG或数据图源需局部修改时保留其原生路径，不由本模块重新生图。此模块收到上游已定brief/布局/标签时直接复用；仅本轮变化使相关事实不成立时补查。用户明确选择OpenRouter/API才读相应服务文档，单说模型名称不改变调用渠道。

若用户将精确型号作为硬条件，而当前工具无法指定或核验该型号，先说明可用能力并解决这次调用的型号/路线；不静默替换，也不自动转付费API。普通风格草稿按实际可用工具生成并如实记录型号可见性。

## 三稿怎样才可比较

新一轮风格探索默认生成三个独立图稿，分别调用、保存并审查；按用户明确数量调整。所有版本共享核心内容、面板顺序、视角、构型计数、物相角色和文字台账。主要改变描线、填色、体积与纹理，形成真正不同但科学含义一致的候选。

可用的三个方向按图型选择，不固定期刊品牌：

| 方向 | 视觉语法 | 适合 |
|---|---|---|
| 清晰平面线描 | 清楚轮廓、平面低饱和填色、少量纹理 | 机制、比较、分类、流程 |
| 克制淡彩剖面 | 薄轮廓、轻微明暗、材质可辨、柔和局部过渡 | 组织界面、多尺度、解剖示意 |
| 技术剖视/轴测 | 一致透视、有限渐变或排线、清楚装配关系 | 器件、制造、材料结构 |

同一论文可以更换第三方向，例如高信息密度机制网络用分区线图，不强行加轴测质感。用户的参考风格优先。标注“Acta 风格”时需把它翻译成从实际参考图总结的可操作规则。

## 形状与文字分开

默认优先生成无字插画层，并预留标题、标签和方程空间；用独立文字台账规划或排版。若用户需要带字灵感图，可以让模型放短标签供比较，但这些文字须核对，进入原生稿时全部重新建立为真实文字。

形状层不包含烘焙标签、伪字或字母轮廓；方程也由独立文字/结构对象建立。已有有字图作为参考时，绘制时依据它的形状、逐对象重建，并跳过其中的文字像素。

## 生成规格模板

```text
用途与阶段：主文示意图/图形摘要；内部探索/候选制作
读者应理解：<一条科学核心句>
内容主版本：<文件与版本>
参考图角色：图1控制内容/几何；图2仅控制线条、配色、材质
科学实体与关系：<按面板列最小充分清单>
构图：<阅读顺序、面板比例、对应位置、留白>
本候选风格：<清楚、具体的线/色/材质描述>
形状层：<要求的对象、相区、遮挡与计数>
文字：<无字并预留位置，或经核对的短标签清单>
共同约束：<必须保留的内容、结构、方向、尺度性质>
输出：一张完整图；规定长宽比与背景
```

从用户给定的范围写提示词。涉及材料微结构、反应式、解剖和器件时使用已核实的构造，不能交给模型自由补全。

提供本地参考前先查看。多个参考明确各自权限；工具支持路径时用已查看的路径，不支持时使用其规定的图像引用机制。记录实际工具、可见模型标识、时间、提示词、参考角色及输出位置；型号未暴露就照实记录。

## 每张都先自审再推荐

应用 [review](review.md) 的科学、视觉与文字检查。把三张图以相同大小并列或分别展示；每张说明最主要优点与实质问题，并给推荐理由。不要仅给三个链接而跳过内容判断。

若某稿明显错误，先修复或明确标为待修候选，再让用户比较。三个风格不能修复共同的科学缺口；发现共同缺口时回到 brief 的相应条目，统一改正后再比较。

## 选中后的精修

以被选图为内容基线，每轮聚焦一组相关问题：

1. 列出本轮变更 `delta`。
2. 列出容易被牵连的固定项 `locked`。
3. 需要恢复旧风格时，指定旧参考仅控制哪些属性。
4. 生成后看目标局部，再看整图与固定项。
5. 采纳为新基线或退回上一接受版，记录理由。

```text
编辑对象：<当前接受版>
本轮改变：<位置、目标状态、具体关系>
保持：<科学内容/对象数/文字/布局/几何/其他面板>
风格参考：<文件>只控制<指定属性>
检查：<2–5项本轮验收条件>
```

局部修订通常只产出一个新版本；用户明确要求三个时再做三稿。相同几何缺陷连续两次没有改善时，先判断限制是否来自生成方式：已授权原生重建则转 Affinity；否则保留可用候选并说明最小下一步。不要用反复整图生图修复一个字或一条线而持续引入回归。

风格稳定、主要内容已定且用户需要可编辑稿时即可进入 vector。无需把位图雕琢到像素级完美才开始矢量重建。
