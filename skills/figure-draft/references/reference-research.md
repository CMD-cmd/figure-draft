# 参考图调研

适用于找期刊参考、建立风格方向、从用户图提取视觉规则。已有选定参考且只改局部时，直接分析该参考的相关属性。

## 先确定检索用途

分开两条资料线：

- **科学证据**：支持图中实体、关系、结构和适用条件的原始来源。
- **视觉参考**：帮助组织空间、层级、配色、线条、材质和文字的图例。

两条线可以来自同一论文，也可以不同。好看的图不自动支持新课题的机制。

## 选择入口

- 用户给了参考图：先实际查看，识别它控制内容、布局、画风还是局部对象；来源/许可信息按实际用途补充。
- 指定目标期刊：查该期刊同类型、同用途的已发表图，再用邻近高质量领域扩展，避免把刊名当作一套固定滤镜。
- 没有期刊：按科学任务进入[类型索引](taxonomy.md)，从已有语料选少量相关例子。
- 用户要求广泛调研：按类别、学科与期刊分层取样，并保存覆盖表。不要用同一主题十张近似图代替类型覆盖。

## 检索和核验

用主题词与 `schematic / mechanism / interface / workflow / Scheme / Figure`、期刊名组合。优先出版商图页、PMC 原文或合法作者存档。搜索缩略图只用于定位，打开原图和图注后才能写视觉观察。看不到原图时只记录图注已核，不推断颜色、质感或字号。

每条参考记录：论文题名、期刊、发表年、DOI/稳定URL、图号/面板、所读版本、科学用途、布局、色彩语义、形状/纹理、文字、箭头、适用边界、看图状态、许可/署名条件。DOI中的年份与卷期年可不同；作者稿与定稿有题名/排版差异时保留对应关系。

常规新图用约3–6张结构互补的参考即可；需要更广的发现时扩展，达到有效覆盖后停止。整套语料不作为每次画图的必读书目。

## 当前内置语料

- [基础生物学与 CNS](corpus-biology.md)：BIO01–BIO12，机制、空间、时间、分类、技术架构和混合证据。
- [材料与生物材料](corpus-materials.md)：M01–M13，制造、界面、器件、响应递送、结构与功能。

共25篇目的性选取的论文。23篇实际看过图，2篇仅核图注；按条目状态使用。检索核验日期2026-11-04。可先读各语料索引，再用 ID 搜索需要的卡片，不整份载入。

卡片只提供链接和分析，不包含第三方图像。原始论文与图注是引用依据；本 Skill 的布局总结属于设计归纳。

## 从参考形成设计规格

把观察转成6–10条能执行的规则，例如：同物相共用填色；主路径箭头较强；辅助定位线无箭头；有机边界用少数连续曲线；上下标采用独立字形属性；明暗只服务于物相与装配。

记录每张参考借鉴什么，不将整张独特构图、图标或标签体系直接复制。若作者要求改编某张已发表图，核对该图本身的许可和第三方署名要求，再决定重绘/许可流程。

## 调研所得的共同洞察

1. **空间关系常比纹理更重要。** 膜内外、组织层、材料接触与器件装配先于装饰细节。BIO05/08/09、M05/06。
2. **同一比较要固定参照。** 保持视角、尺度、区室和颜色身份，使改变成为视觉焦点。BIO04/06、M05。
3. **箭头承担不同推理。** 运输、化学变化、预测、时间和放大连线分别定义。BIO02/10、M09。
4. **多尺度图保留来源锚点。** 从器官、组织到分子逐层放大，每次跳转对应具体位置。BIO12、M01/03/04。
5. **图内短语不等于信息贫乏。** 结构/空间负责关系，标签负责身份，图注负责条件和来源。BIO01/05、M02/11。
6. **材质应有区分度且服从信息层级。** 链、颗粒、凝胶、金属、骨使用可辨的形状与克制明暗；高光和噪声过强会抢走机制。M05/06/07/13。
7. **示意与数据可同页但身份要清楚。** 圆面积、热图、实验图和模型曲线各有真实数据契约。BIO02/03/07、M02/12。
8. **知名期刊并不存在单一画风。** 同一期刊里流程、网络、组织图和器件图的编码不同，选择依据是当前科学任务。
