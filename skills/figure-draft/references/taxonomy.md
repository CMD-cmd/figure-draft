# 科研示意图类型索引

分类按图的**科学任务**，而非软件、配色或期刊。多数图以一类为主并组合一类辅助。先从下表选中，再只读对应设计卡与一两条语料。

| ID / 类型 | 核心问题 | 典型布局及识别特征 | 深读 | 已核例子 |
|---|---|---|---|---|
| T01 因果/调控机制 | 谁通过什么影响谁？ | 区室内路径，方向箭头与抑制端点 | [机制卡](types-mechanisms.md) | BIO08、BIO11 |
| T02 化学/物相转化 | 底物如何变成产物？ | 反应局部、相区与净式配合 | [机制卡](types-mechanisms.md) | BIO02、M03、M09 |
| T03 材料—组织界面 | 接触处发生什么？ | 剖面、物相带、局部接触与传质 | [空间卡](types-spatial.md) | M05、M06 |
| T04 组织/细胞空间生态 | 谁位于哪里、如何相互作用？ | 解剖锚点、区室、细胞身份与状态分层 | [空间卡](types-spatial.md) | BIO05、BIO12 |
| T05 多尺度嵌套 | 微观关系对应哪个宏观位置？ | 整体定位→局部→内部机制 | [空间卡](types-spatial.md) | BIO10、BIO12、M01、M03 |
| T06 时间/状态演化 | 随时间或条件怎样改变？ | 共同基准的分期条带/状态对照 | [过程卡](types-processes.md) | BIO06、BIO10、M07 |
| T07 合成/制造/加工 | 怎样得到材料或结构？ | 原料→关键操作→结构，必要局部放大 | [过程卡](types-processes.md) | M02、M03、M11、M13 |
| T08 实验/技术流程 | 如何获得和处理证据？ | 输入→采样/处理→读出；分支或迭代 | [过程卡](types-processes.md) | BIO07；BIO03混合总览 |
| T09 结构—性能—功能 | 哪种结构如何实现作用？ | 结构主图＋机制局部＋功能出口 | [综合卡](types-synthesis.md) | M02、M03、M06、M13 |
| T10 递送/刺激响应 | 到哪、何时、如何释放或响应？ | 路径、屏障、触发、局部作用 | [过程卡](types-processes.md) | M01、M07、M09 |
| T11 器件/装配/剖视 | 部件怎样组装并接触对象？ | 爆炸图、轴测图、横截面与植入位置 | [空间卡](types-spatial.md) | M04、M05 |
| T12 对照/扰动/替代方案 | 改了什么、结果如何不同？ | 相同支架/视角的并列或上下对照 | [综合卡](types-synthesis.md) | BIO04、BIO11、M05 |
| T13 分类/概念图谱 | 领域由哪些并列或层级部分组成？ | 树、矩阵、环形分区，统一图标/标签 | [综合卡](types-synthesis.md) | BIO01、BIO05 |
| T14 网络/反馈/循环 | 哪些关系闭合或相互耦合？ | 模块网络、分区通路、明确返回线 | [机制卡](types-mechanisms.md) | BIO07、BIO08、BIO09 |
| T15 转化/验证/决策路径 | 哪些证据使下一步成立？ | 阶段、分叉、判断条件与反馈 | [过程卡](types-processes.md) | 设计扩展 |

BIO 为[生物学语料](corpus-biology.md)，M 为[材料语料](corpus-materials.md)。图形摘要/TOC、主文示意图、综述总览和讲演插图是**用途维度**；同一机制可以面向不同用途重新压缩。实验照片、显微图和定量图另有数据规则，不能通过“示意化”改变原始观察。

另选视觉表达维度：平面线描/淡彩剖面/有限体积轴测；信息密度：概览/局部解释；结构：单图/比较多栏/示意与数据混合。不要将这些维度误写为新的科学类别。
