# 数据绘图模块

当本轮要从真实数据绘图，或改数据标记、坐标、误差线、统计结果及编码时读取。`Figure-draft` 保持流程负责人，自动使用下述能力；用户无需另行调用 `nature-figure` 或 `paper-figure`。

## 先确定操作与图源

| 当前材料/要求 | 执行动作 | 本轮读取 |
|---|---|---|
| CSV/表格 + 新建统计图 | 核对数据、实验单位与图的科学问题；确定一次后端后绘制 | `nature-figure/SKILL.md` 的定量路线及其选中资源 |
| 现有 Python/R 图源 + 局部修改 | 保留语言、真实数据和计算口径，改原图源后重新渲染 | 对应后端与受影响的 QA；已读规则复用 |
| 指定 `paper-figure` 的 JSON/`render.py` 模板 | 按明确选择的 Python 路线执行所选模板 | 相应模板；需要出版验收时借定量 QA |
| 只有数据图截图，要求复刻 | 先找同任务中的表格/脚本；缺失时区分外观布局稿与明确说明误差的数字化近似 | 所选图型规范和数据来源记录 |
| 只审核数据图或其图注 | 看实际图和现有方法/数据证据，列明能核实的内容 | `nature-figure/references/qa-contract.md` 或 `figure-legend-conventions.md` 的相关段落 |
| 已完成数据面板只组版/改格式 | 保留冻结资产，按比例放置或从既有源导出 | 本 Skill 的 [delivery](delivery.md) |

截图不作为恢复真实动物记录、单个样本或统计检验的依据；原始实验结果不通过 imagegen 重画。显微图、条带和照片保持真实影像身份，按原始文件及期刊的图像完整性规范处理。

## 使用定量能力库

已安装 `nature-figure` 时执行下列接入步骤；当前环境采用其他绘图工具时，使用文末的直接绘图步骤。

1. 从技能目录定位已安装的 `nature-figure`。首次实际定量绘制读其入口，后续复用仍有效的规则；只查规范时直接读相应 reference。继承已定科学问题、布局、标签、尺寸和证据映射。
2. 按该 Skill 的既有规则确定 Python/R：当前明确选择、语言特定图源、任务已定选择、已保存偏好。只在这些均不能确定时询问一次技术选择；这不是要求用户选择或调用另一个 Skill。已有 R 图源不因 Python 模板方便而换后端。
3. 只加载一次定量 core 和选定后端片段。图型不确定才查图型索引，多面板科学论证需要重排才查证据架构；模板适配只读选定模板及适配要求，不加载另一后端或全部模板。
4. 保留真实数据、单位、样本/配对关系、过滤、缺失、变换与统计定义。新的推断分析若超出用户本轮绘图范围，先完成可独立的布局/数据检查，再解决所缺分析决定。
5. 执行适用的源码、最终绘图区对齐、PDF 字体/碰撞检查，并在最终物理尺寸看每个面板和整图。已有有效证据复用；新渲染或修改触发相应复查，不把同一验收按多个 Skill 重复执行。
6. 返回当前 Figure-draft 阶段：图源/数据版本、后端、导出文件、实际 QA 与待核事实。混合图替换对应面板后再检查整图尺寸、对齐和字形。

定量规范以能力库为单一来源，此处不复制其脚本、阈值或完整工作流。借 `paper-figure` 的 Python 模板只提供一次执行，不重新选择后端或转回入口。对已完成面板的等比例组版与改变其数据编码分别处理。

## 使用现有工具直接绘图

1. 沿用现有 Python/R 图源或当前任务已选语言。新建图且语言仍未定时询问一次 Python/R，把选择记入任务状态。`nature-figure` 的偏好脚本只在该 Skill 实际安装时使用。
2. 检查原始表、样本单位、列名、单位、分组、配对、缺失值与变换，列出各数据列对应的轴、颜色、形状和误差表示。
3. 用选定后端生成可重复运行的图源，保留输入数据与统计定义。误差线、检验和样本数从实际方法与数据获得；遇到未定定义先补齐该信息。
4. 按最终物理尺寸渲染，核对点数/分组、刻度、误差线、图例、字体、可比面板的绘图区及标签位置。保留渲染后的测量或检查记录；需要时使用当前环境可用的对齐和 PDF 字体检查工具。
5. 保存图源、数据版本、导出与检查记录，再回到当前阶段；混合图替换对应面板后检查整图。

工具连接和安装按[接入说明](integrations.md)处理。现有图源可完成的局部修改直接接续，具体缺失的检查单独记录。
