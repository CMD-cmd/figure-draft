# 导出、图注与正文整合

只交付当前请求所需阶段产物。常见成品包包括：原生 `.af`、保留文字的 SVG/PDF、用途所需的 PNG/TIFF、文字台账、图注，以及简短的来源与验收记录。按目标格式选择，不为凑包生成无用途文件。

先分辨子任务：只导出读下节；只写图注读图注节；整合正文才读正文节。已有可用图源直接接续，纯格式转换不补做科学立项、风格探索或Affinity重建。目标期刊未变且已有有效规格时复用；单纯按明确尺寸转格式不以重新检索投稿政策为前提。

## 导出与结构检查

1. 继承用户或已核规范给出的最终尺寸、色彩空间、分辨率和文件类型。仅当投稿规格缺失/失效时补查目标期刊；不能把某期刊数字当作通用规范。
2. 从现有主图源生成本次要求的格式；SVG/PDF交付保留文字可编辑，轮廓版另存。只要PNG/TIFF时直接渲染，不强制新增PDF/SVG或 `.af`。
3. 检查透明度、裁剪、渐变、线端与字体的实际导出表现。PDF 字体清单出现第二字体时定位具体字形，判断是否合理 fallback。
4. 位图像素宽度 = 最终宽度 mm ÷ 25.4 × dpi。只修改 DPI 标签不会增加原有像素细节；从原生矢量按真实尺寸重新渲染。
5. 本次生成纯矢量SVG/PDF时对实际文件运行 `audit_vector.py`；仅PDF且无SVG时用PDF检查能力，不能为满足该脚本的必填项伪造SVG。仅位图导出检查像素、尺寸和视觉，不强制执行矢量脚本。返回 0 的 `REVIEW` 仍需人工处理；1为结构失败，2为无法审计，逐项读取findings。
6. 打开实际保存的最终文件，看最终尺寸、全部面板与高风险局部；请求包含原生稿时完成其保存重开证据。

该脚本接受 `--svg PATH [--pdf PATH] [--labels PATH] [--out PATH]`。SVG 使用标准库；PDF 检查需要 PyMuPDF。缺依赖仅影响对应检查，记录确切缺口；在获准的任务环境安装后重跑，不把未审计写成通过。

PDF 的渐变与图片需区分。部分 PyMuPDF 版本的 `get_image_info()` 会把矢量 shading 的临时渲染计入 image block；脚本结合图片绘制操作、资源与 Image XObject 检查，保留原生渐变并识别内联图片。不要单靠一个图像计数宣布“有位图”或“无位图”。

零嵌入位图是纯矢量结构检查的一项，不证明原生对象编辑性。带真实显微图/照片的混合图保留有来源的图像：核对影像清单、来源、分辨率和未经改变的内容；可在单独导出的示意部分运行纯矢量检查，整图按混合图验收。不要把该脚本对合法照片的 FAIL 作为整图失败或删除影像的依据。

组装已完成的R/Python图、照片与示意面板时，给每个面板保留来源/后端/版本，以用户指定或现有工具组版。冻结数据图的标记、轴、图例编码和数值不变；只做等比例放置，在最终尺寸检查字体、比例尺和可比对齐。若需改数据标记或重绘，回到原后端后再替换。分面板检查与最终版面检查各做一次，不把完整绘图流程按每个Skill重复执行。

## 图注按当前图重写

用户只要求图注时，查看当前图及有关证据后直接撰写；不打开绘图应用或要求Python/R。仅需期刊图注格式时借用 `nature-figure` 的对应参考段落，不启动其绘图路线。

图注按“图的主题 → 面板内容 → 图中符号/线型/尺度解释 → 必要来源、范围与声明”组织。按期刊规定补全统计、缩写和 AI 使用声明。

- 每个物相、箭头和小图都能在图中定位。
- 图里删除/融合了元素，相关旧说明同时替换。
- 条件性机制用清楚的条件句；不把整段工作争论搬进图注。
- 参考文献对应实际原始研究与适用场景，示意标签不扩大临床结论。
- 研究示意与真实观察图的身份清楚。概念性粒径、相区比例与器件尺寸在必要处定义。

初稿图注可由本阶段直接完成；涉及正文论证重构时才进入 `nature-writing`。正式 reviewer 触发的变更由 `nature-response` 维护意见—改图—正文—回复的映射。

## 放回正文

用户授权整合后：

1. 以实际主稿建立新版本，保留旧文档与原图。
2. 替换正确图位，保持长宽比与足够清晰度。
3. 核对首次引图、面板名、材料术语、机制解释与图注一致。
4. 将图内承担的信息和正文的论点分工明确；优先替换/压缩重复说明。
5. 保护 Zotero/交叉引用字段；渲染相关页与整稿做必要版式检查。
6. 独立记录 `native_figure_version` 和 `manuscript_figure_version`，直到真的替换完成。

Word 字段的包结构检查与桌面 Zotero Refresh 是不同验证；按实际做过的操作报告。

## 交付表述

先给主文件和可预览图，再说明完成的关键改动、已验证项和影响使用的缺口。图内与公开说明使用接受后的正向内容。工作记录可保留实际变更与失败原因。

正式投稿候选核对 [期刊与来源](policy-and-provenance.md)；相同用途和目标下复用仍有效的已核记录，临近实际投稿再确认时效。原生矢量稿、作者科学认可、期刊政策检查和实际投稿分别记录。
