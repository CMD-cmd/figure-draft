# 工具与技能接入

在首次执行生图、原生编辑或数据绘图，以及对应能力暂不可用时读取。先查看当前环境的工具目录、已安装技能和已有图源，再选择当前阶段需要的能力。

## 选择执行方式

| 当前任务 | 可用能力 | 接入方法 |
|---|---|---|
| 科学内容、布局或图注讨论 | 论文、记录、图稿和语言能力 | 直接使用本 Skill 对应模块；证据不足时补查原文 |
| 参考图检索与分析 | 浏览、文献检索、Zotero 或用户参考图 | 打开相应图与图注，记录来源和可借鉴的视觉规则 |
| 示意位图生成/编辑 | 当前环境的图像生成工具 | 读取实际工具 schema；有 `imagegen` Skill 时按需读取它 |
| Affinity 原生绘制 | Affinity MCP 与应用 SDK | 有 `affinity` Skill 时使用其操作规则；否则读 MCP 的 preamble 和对应 SDK 文档，再按本 Skill 的 Affinity 模块执行 |
| SVG 与参数图源 | 文件编辑、脚本及 SVG 渲染器 | 保留源格式；有 `paper-figure` 时只借当前图型的规则或模板 |
| 数据绘图 | Python/R 图源、运行环境及真实数据 | 有 `nature-figure` 时使用其定量规则；否则按本 Skill 的数据模块检查并绘制 |
| 独立复核 | 获准的独立执行者及实际图像查看能力 | 提供当前图稿和科学简报，核实看到的文件与返回意见 |

## 按需复用辅助技能

`nature-figure` 提供定量图与期刊规范，`paper-figure` 提供结构图与模板，`affinity` 提供原生应用操作。根据技能目录中实际存在的名称与路径定位；这些资源按对应任务读取。

写作可接入 `nature-writing`，正式审稿回复可接入 `nature-response`。文字表达保持直接，图内用短标签，证据与必要范围放在图注或正文。安装了 `anti-defensive-writing` 或 `no-negative-echo` 时，可在相应写作阶段复用它们。

调用辅助技能时携带主文件、当前阶段、已定内容和风格、本轮修改及输出要求，完成后回到当前阶段。已有流程负责人保持不变。

## 当前工具有缺口时

先完成不依赖该工具的内容、布局或来源核对。需要实际生图、原生编辑或渲染时，说明具体缺哪项能力，并在用户授权范围内连接或安装。继续使用已能工作的工具和任务副本。

用户明确选择外部模型时，按当前聊天授权和相应工具规则提供材料。工具的实际名称、参数、模型与权限以当前环境为准。
