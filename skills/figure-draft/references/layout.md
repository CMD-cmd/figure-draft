# 布局与视觉语言

适用于布局讨论、排版重构或三稿探索前的构图固定。

## 从关系选布局

先看[类型索引](taxonomy.md)。内容关系决定阅读路径：比较用共同基准，过程用顺序，空间机制用位置，尺度关系用嵌套，反馈用回路。可以组合两种拓扑，但让一条主路径保持显著。

先用低成本线框、简单矢量或文字面板表讨论，不急于生成精细质感。布局方案应真正改变阅读路径或信息分工；同一构图换颜色属于风格候选。

| 布局参数 | 必须做出的决定 |
|---|---|
| 成品画布 | 用途、长宽比、最终物理宽度；期刊未定时标为暂定 |
| 面板角色 | 每栏/每层承担的科学功能与阅读顺序 |
| 视觉主次 | 主机制、定位背景、辅助状态各占多少空间 |
| 对齐 | 共享基线、面板标题锚点、重复对象尺度、间距 |
| 标注空间 | 文字安全区、引线通道、方程/图例位置 |
| 尺度 | 哪些是真实比例，哪些是概念放大或并置 |

用户要求讨论布局时，通常提供两种有实质差异的线框并推荐其一；有明确现图或已选方案时直接复用。内容未定的情况下只做足够支持讨论的草图。

## 视觉语法

建立少量有语义的设计 token，而非为每个面板独立装饰：

- 同实体同色系、同线宽家族、同形状规则；不同物相通过明度、轮廓、纹理与必要标签共同区分。
- 背景、上下文和辅助线降低显著性；核心关系保留清楚对比。减淡以后仍要在成品尺寸可见。
- 保持一套透视/剖面规则；概念分子图与器件图尺度不一致时用空间分离与图注解释。
- 重复器件使用共享母形与参数。镜像时检查左右、流向、手性和文字。
- 有机边界用有原因的缓慢起伏与局部层次。规则器件保留几何规律；随机抖动不自动成为“自然”。

## 线、圈和箭头的语义

| 形式 | 默认作用 | 核查 |
|---|---|---|
| 无箭头细引线，必要时端点 | 标注某个实体或位置 | 末端是否在正确物相/对象上 |
| 明确方向的箭头 | 转运、反应、步骤、力或调节 | 起止对象、方向与证据一致；不同功能有图例 |
| 带抑制端的线 | 抑制关系 | 不与普通封口/截断混淆 |
| 虚线轮廓 | 旧边界、隐藏/假设关系等其中一种 | 同一线型避免承担冲突语义；图注定义 |
| 定位圈及连线 | 指明放大图取自何处 | 圈内原图尺度不变，方向与上方对应 |
| 放大 inset | 另一个尺度的细节 | 放大内容与原位置、左右和前后关系相符 |

定位圈是覆盖在原图上的注记；不能把圈里的螺纹或组织局部缩放成“镜头”。若用户要真实局部放大，单独建立 inset 并清楚标注。

优先用明确空白通道布线，端点落在圈边或实体上。只有在语义需要时用曲箭头；定位线是否直线服从已定规格。实际遮挡通过合理图层顺序解决，避免用宽白色遮罩切掉科学细节。

## 字体计划先于定稿

确定字体家族、正文标签、面板标题、面板字母和化学式层级。以最终物理尺寸评估，数值以目标期刊当前要求为准。未知期刊时可暂用正文 7–9 pt、较大标题与 0.4–0.8 pt 轮廓作为起点，明确这是设计起点。

长标签先改短或合理换行，再调整位置和面板空间；保持文字自然比例。上下标、希腊字、负号、prime 号需要有字形覆盖的字体和真实字符/排版属性。避免仅凭字体名认定所有符号实际都用了该字体。

阶段完成：科学内容和布局已匹配，后续三个风格候选共享这一内容/布局契约。确需同时探索布局时，把布局与风格变化分别命名记录。
