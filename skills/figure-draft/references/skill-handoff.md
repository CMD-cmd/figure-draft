# 统一入口、能力库与最小交接

在多个模块同时适用、从另一个入口接入或职责不清时读取。普通单阶段工作复用入口中的规则即可。调用 `$figure-draft` 后由当前 Agent 自动选择模块并使用其所需能力，用户不必逐个调用其他 Skills。

## 按当前产物选模块

从 Figure-draft 进入的任务始终由 `workflow_owner: figure-draft` 维护版本、阶段、固定项和交付。专业能力库提供技术规则与执行方法；一次借用不改变流程负责人。

| 当前要做什么 | Figure-draft 内部模块 | 仅在需要时读取的能力库 |
|---|---|---|
| 科学职责/机制/布局讨论、期刊参考、三风格生图、插画迭代 | brief / layout / reference / image-generation 中匹配的一项 | 原文检索；实际生图才用 imagegen |
| 已定节点和关系的 SVG 框图/流程图；指定参数图源 | vector-editing | paper-figure 的选中图型；指定 Affinity 操作才用 affinity |
| 从真实数据新画或修改定量图 | data-figures | nature-figure 的选定后端与 QA；Python 可借 paper-figure 模板，R 保持 R |
| 指定 `.af` 改字、移动形状、导出或检查图层 | affinity；只导出时先用 delivery 的导出小节 | affinity 的连接与对应文字/矢量/导出 SDK |
| 已有图只写图注、审稿或核查期刊规格 | delivery 的相应小节 / review | nature-figure 的图注/QA/期刊段落；不启用绘图后端 |
| 已有成品改格式/分辨率，或组装固定面板 | delivery | 既有源格式的渲染器/编辑器 |

同时显式指定多个 Skills 时按其实际职责组合，不依次完整执行。用户直接调用 nature-figure、paper-figure 或 affinity 的独立任务可保留该入口；需要本 Skill 的某阶段时只返回相应产物，不接管上游流程。未指定工具时以已有图源、当前确认和目标交付格式决定；只有这些无法消除的实质歧义才询问，不问用户“要调用哪个 Skill”。

## 避免循环和重复读取

- `figure-draft → paper-figure`：交付已定节点、关系、标签、画布和样式；paper-figure只完成所选类型的制作/修改，不再转回科学立项或风格探索。
- `figure-draft → affinity`：交付目标源/副本、当前 sessionUuid（接收方读回核实）、对象/文字台账与改动；已完成的连接发现、preamble和副本保护复用，不新建第二份无用途副本。
- `figure-draft → nature-figure`：数据模块传入已定后端、图源和本轮任务，只执行相关定量路线。工作流负责人仍为 figure-draft；不把混合图的示意面板再次送回 figure-draft 入口。
- `nature-figure → figure-draft`：非数据示意任务在前置分流后结束本地绘图路线；不得继续载入 Python/R 片段和 flat-SVG gate。
- 借 `nature-figure` 的期刊/图注/影像规则：直接读相关 reference/section；不把“读一个规范”升级为新绘图任务。
- 纯结构图按所选图型查规范；生物材料插画按科学任务查参考图。两个索引用途不同，按问题选择。
- `codex-figure-workflow` 的项目源码制图、`visual-acceptance-loop` 的浏览器截图检查只在实际采用那条执行路线时使用。Affinity的原生渲染、只审图、只导出不因此被要求新建网页或安排一整套独立裁判。

可在上下文或状态文件记录已读文件、章节及适用的图源/版本。记录是索引，不能代替未带入当前上下文的必要规则；源文件变化时重新读受影响段落。不要仅因进入另一个阶段，就重新读仍有效的整套能力库。

若关联 Skill 没安装，先用当前可用工具完成其范围或定位具体缺口，再按当前授权处理安装；单纯转交不增加付费或外部生成权限。命名模型（如 GPT Image）不等于指定 OpenRouter/API。保持用户明确选择的服务。

当前环境的能力选择与直接工作入口见[工具与技能接入](integrations.md)。

## 交接记录最小字段

```text
任务阶段、图类别与负责流程（从本入口开始时为 figure-draft）：
主图源/版本、目标副本或导出：
已定内容、布局、风格、标签和物理尺寸：
本轮改动与固定项：
执行方式：imagegen / native-affinity / svg-script / python / r / assemble-only
需加载的参考段落、已读且有效的文档：
本轮验收及仍待核事实：
```

普通小改动可放在上下文中，不强制增加状态文件。已知字段直接继承，缺字段只在影响当前动作时补齐。

## 规范与验收适用范围

用户当前要求与目标期刊的适用规则、已确认的图内容/样式、当前执行方式的技术限制依次约束动作；样式预设仅补空白。保留数据的真实编码、可编辑文字与来源等完整性要求。

| 验收对象 | 使用什么 | 不由它证明什么 |
|---|---|---|
| 纯矢量插画 SVG/PDF | 本 Skill `audit_vector.py`＋实际视觉/原生检查 | 科学正确、无碰撞、原生可编辑性仍另查 |
| 选定 Nature flat-SVG 规范的新框图 | `nature-figure/audit_svg_schematic.py` | 不用于有原生渐变的插画、合法照片混合图 |
| Python/R 定量图 | nature-figure 数据、对齐与PDF验收 | 不替代机制示意的内容审核 |
| 真实影像＋示意＋固定数据图混排 | 分面板来源检查＋最终尺寸/对齐/字形审核 | 不能用整图零位图或另一后端重画来“修复” |

缩放/移动固定面板时保持长宽比、数据标记、坐标和颜色映射；在最终组版尺寸重新检查文字、比例尺与可比面板对齐。需要改变数据、统计、轴、图例编码或数据标记时，回原后端重生成并替换资产。
