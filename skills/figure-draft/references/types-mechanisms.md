# 机制、转化与网络设计卡

仅按当前类型读取对应段。例子全文与图页在[生物学语料](corpus-biology.md)和[材料语料](corpus-materials.md)。

## T01 因果/调控机制

**结构**：先列实体、所在区室、关系类型及证据，再安排主路径与辅助支路。膜、细胞器与组织边界承担科学约束。

**视觉**：反应箭头、抑制T端、转运线和标签引线用不同端点/位置；颜色区分实体家族，不为每条关系增加一种色。复杂分子可用文字节点，空间关键实体保留简化形状。

**验收**：箭头是否跨正确膜；抑制是否被画成激活；结合、表达和功能效应是否混同；是否把文献综合误呈为同一实验完整证明。

**例子**：BIO08铁死亡网络保留膜和转运体定位；BIO11巨噬细胞图同时使用方向和抑制关系。借鉴拓扑时，旧表型分类要按当前科学任务重新核对。

## T02 化学/物相转化

**结构**：分开输入物质、反应位置、溶解/释放产物、剩余固相以及环境因素。化学式与空间机制各解释自己的问题。

**视觉**：链长/断端表达聚合物状态；相区与颗粒表达物质身份；短标签定义实体。方程可放共同底栏，避免在多个同机制面板重复。

**验收**：配平与电荷；链交叉是否误成化学交联；水解、质量损失和机械丧失是否被压成一步；化学图使用真实原子/键含义，概念链与真实结构式分开。

**例子**：BIO02以速率符号连接分子过程与模型；M03把分子马达与宏观收缩连接；M09将不同反应角色绑定各自组分。图上箭头方向须以原文机制为准。

## T14 网络、反馈与循环

**结构**：先分辨真实闭环、并行支路和循环排列的分类。真正反馈要有返回对象、返回内容与触发条件；环形版式本身不建立生物循环。

**视觉**：主路径稳定、回路线可追踪；节点按功能模块或空间区室分组。分支多时用分区或子图，优先保持关系可追踪。箭头粗细只有定义了含义才可编码强弱。

**验收**：回路是否有证据；跨线是否误成节点；输入/输出、对称/非对称作用、预测与实测身份是否明确。

**例子**：BIO07 AlphaFold 的回收路径是计算迭代；BIO08是调控网络；BIO09以多条膜运输路径共享阶段。三者不能只因都有箭头就换成同一个循环模板。
