# 每轮视觉验收

适用于生图、自审、独立复核和每次可见修改。只审图时先读图和相关事实，不启动完整绘制路线。

## 看什么、以什么尺寸看

1. **整图**：第一眼能否识别主旨、面板关系和阅读顺序；有无多余视觉重心。
2. **最终物理尺寸**：文字、细线、色差、上下标与必要纹理能否辨读。高分辨率放大截图不能代替这一步。
3. **逐面板**：所有实体、方向、关系和标签是否准确完整。
4. **关键局部 200–800%**：连接、遮挡、断端、边界、定位圈、字形。放大图要保留局部在整图中的坐标/面板身份。
5. **修改前后同位置**：目标变化有效，锁定区域没有非预期退化。只在有明确保护区域时做像素差；正常抗锯齿和文字重排会影响像素差。

复核输入至少包括当前整图、相关局部、核心句、文字台账、改动与固定项。独立 reviewer 的结论必须说明实际打开了哪些图；文件路径、OCR摘要或生图提示词不能冒充看过图。

仅有位图时，描述观察到的字形、层级与相对大小；精确字体名称、字重与物理字号需要源对象/字体元数据和最终尺寸核对。

## 六组检查

| 组 | 核查内容 |
|---|---|
| 科学与内容 | 实体/物相、化学计量与电荷、解剖、证据层级、因果/相关、先后/并存、尺度性质 |
| 形状与几何 | 曲线连续、交叉/交联、正圆、装配遮挡、穿插、断面贯通、数量、重复构件长度与透视 |
| 配色与质感 | 同物相同画法；明度足以区分；粗糙/光泽符合材料身份；界面过渡清楚；色盲/灰度仍可读 |
| 布局与引导 | 边距、对齐、重心、留白、引线起止、圈与 inset 的位置方向、箭头语义、密度均衡 |
| 文字与符号 | 拼写、术语、字体/字重、最终字号、自然字宽、基线、换行、符号 fallback、上下标、方程 |
| 原生与输出 | 图形/文字分层、对象有意义、保存重开、导出格式/尺寸、嵌入位图、版本与图注匹配 |

“AI 感”转成可修改的观察：材料普遍过亮、玻璃/塑料高光不分相、无因果的纹理噪声、随机颗粒、重复图形漂移、视角混杂、细节融化、伪文字、夸张光晕与过密装饰。针对观察修正，不能把“越平越好”或“所有渐变都删掉”当作标准。

不规则性也要受约束：粒径可有变化但不能无来源地跨数个数量级；骨孔形态可不同但边界保持连贯；相区可以有局部变化但物相仍可辨识。

## 问题要能执行

```text
ID | 版本/面板/坐标或对象ID | 观察 | 科学或阅读影响 | 建议动作 | 优先级 | 修复证据
```

- **P1**：错误科学关系、错误反应式/对象身份、虚构数据或误导性的核心表达。完成候选前修复。
- **P2**：错位、穿插、不可读文字、错误引线落点、明显风格冲突、结构可编辑性失败。完成相应交付前修复。
- **P3**：不改变解释的局部润色。按效益处理，留理由即可。

“很乱”“不够高级”需要转换为具体位置和原因。每条意见由主执行者重新看图和必要源对象核验；视觉模型对计数、物相、坐标、白描边和曲线的识别可能错误。记录采纳、部分采纳或不采纳及证据。

## 独立复核

当图复杂、多轮变化较多、接近交付或用户要求时，使用当前获准的独立执行者。提供当前科学简报与冻结图，不提供希望 reviewer 得出的结论；需要回归检查时另外给变更表。

Gemini 只在当前聊天授权后使用相应 Skill，核对实际模型和图像读入范围；失败、材料截断或没有看到图时记录未完成，不能计作一次通过。原生子 Agent 也须遵守实际模型路由规则。

独立意见的投票数量不决定科学正确性。主执行者结合图像、原生结构与证据裁决。

## 何时停止

单独审图以问题清单完整、位置和证据可核查为完成；交付审查意见不以问题已修复为前提。下面条件用于生成、修图或成品验收。

- 本轮指定问题已解决；
- 无未解决 P1/P2；
- 锁定内容无回归；
- 最终尺寸、局部、文字和请求范围内的文件检查已完成；
- 若安排了独立复核，其材料范围与结论可核验。

不固定要求每次三轮。新发现或新修改触发相关复查；已完成且无新风险的检查无需机械重复。用户仅要讨论稿时可交付有标明问题的候选，不能把它写成原生或投稿验收通过。
