# 材料界面图：从内容梳理到可编辑图稿

设想一张比较三类材料与组织界面的科研示意图：三栏并列回答同一个问题——材料在局部环境中发生了什么变化，这些变化又怎样影响它与周围组织的接触界面。下面展示各阶段如何衔接，以及如何从中途阶段直接接续。

## 1. 内容与布局（`brief` → `layout`）

先为每栏列出材料主体、邻近组织、界面过渡区、关键过程和反应产物，逐项对应论文正文或实验记录，明确哪些关系用图形表达、哪些适用条件留在图注。把整张图的核心结论压成一句话后，再进入布局讨论。

三栏比较采用一致的观察视角和主体尺度，重复构件共用几何参数；各栏内部则保留自身真实的物相、接触关系与物质输运过程。宏观定位圈指明取景位置，局部放大图展示界面微结构，二者通过无箭头定位引线准确对应。

## 2. 风格探索与局部精修（`explore` → `refine`）

在科学内容、面板顺序和主要几何关系固定后，生成三个不同画风的候选稿（如清晰平面线描、克制淡彩剖面、技术剖视质感）。每张候选稿先分别检查实体身份、箭头方向、标签、遮挡关系与物相边界，再以相同尺寸并列比较。

选定主方向后，在状态记录中分开绑定内容主稿（`content_master`）、风格参考（`style_reference`）、几何参考（`geometry_reference`）和文字台账（`text_master`）。后续精修若想借用另一稿的线条粗细或配色，只需指定该参考图仅控制对应风格属性，继续沿用当前已确认的科学内容与几何结构。

## 3. 原生矢量重建（`vector`）

进入 Affinity（`.af`）或 SVG 制作可编辑矢量稿时，遵循“先图形、后文字”的两条独立制作线：

- **形状层**：规则构件用原生几何形状或布尔组合，有机组织边界用少量连续 Bézier 曲线；金属、颗粒、聚合物链与组织分别采用可辨识的画法。同一种材料跨面板保持一致的颜色与描边规则。
- **文字层**：按 `labels.json` 独立创建真实文本对象，化学式与电荷使用真实字符及原生上下标属性，不把文字描摹成路径或融进背景像素。

按科学实体分组命名，重复部件共用母形或参数。修改某个标签后同步核对相邻引线落点；修改共用构件后检查所有出现位置。

## 4. 每轮检查与交付（`review` → `deliver`）

每次生成或可见修改后，依次查看目标局部（200–800%）、整图与最终刊印物理尺寸：核对科学关系是否准确、引线是否落在目标物相上、曲线是否连续、文字是否清晰可读，以及锁定区域有无意外退化。原生稿完成后做可逆的改字、移点与保存重开测试；纯矢量导出可配合运行 `audit_vector.py` 核对文本与位图结构。

交付时分别记录图源版本、正文嵌入版本和图注版本，提供本次请求格式的文件，并清楚列出已完成的检查项与仍需作者确认的科学事实。

## 5. 从中途阶段直接接续

实际使用中不必每次从第 1 步开始，可直接从手头已有产物切入：

- **已有选定的位图草稿**：按本轮要求进入 `refine`（局部精修）或 `vector`（重建为 `.af` / SVG 可编辑对象）。
- **已有 `.af` 或 SVG 矢量稿**：沿用原图源改字或调线，核对修改处与整图。只导出时，从当前主文件生成目标格式并检查此次导出。
- **已有 Python/R 数据面板需与示意图拼版**：数据面板保持原脚本与真实数据身份不变，仅在 `deliver` 阶段与示意面板按出版尺寸等比例组版并统一图注。

这套阶段接续方式同样适用于器件爆炸/剖视图、细胞信号机制图和材料制备流程图。具体面板数量、视角、形状规则与配色均由当前图的科学任务决定。
