# SVG 与参数图源直接接续

用户已有 SVG/脚本，或指定交付 SVG 时读取。需要 `.af` 原生对象时走 [Affinity](affinity.md)；仅有源格式转换请求时走 [delivery](delivery.md)。

1. 确认主图源。若SVG由脚本/配置生成，改声明后重新生成；手绘SVG则保留现有组、ID、形状、文字和样式。先检查当前渲染。
2. 按当前请求工作：改一个标签只定位相应文字与相邻区域；改连线只核对起止与路径；只导出直接使用现有图源。无需重新选择图型、确认整份brief或生成三种画风。
3. 已定拓扑需要新建/重排时，若可用，读 `paper-figure/SKILL.md` 的接入规则并只查所选图型。接收已定配色、字体、尺寸与关系，不套用新的灰度或框图预设。
4. 文字保留真实文本；有机形状用有意义的曲线。保留已有且有作用的原生渐变。用户选定纯flat-SVG规范时才执行对应的禁渐变审计。
5. 可见改动后渲染局部与整图；导出格式/尺寸变化后检查实际导出。纯矢量结构需要时用 `audit_vector.py`；照片与数据面板按各自来源验收。
6. 保存新版本或已授权的任务工作副本。只交付要求的文件和必要检查记录，不为一个SVG改字建立Affinity工程。

目标“1∶1复刻”包含拓扑、文字与视觉三项要求，先确认参考内容与可编辑对象的对应关系；图源存在并不证明相似度。需要美术重构或内容调查时才回到相关阶段。
